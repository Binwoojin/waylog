# Frontend Audit Skill

Use this skill when performing a frontend quality review.

## Review Checklist

- Component architecture
- State management
- API integration
- Loading state
- Error state
- Empty state
- Responsive design
- Accessibility
- Performance
- Maintainability

## Output Format

### Must Fix
### Should Improve
### Nice to Have
### Keep
