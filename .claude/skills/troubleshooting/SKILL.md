# Troubleshooting Skill

Use this skill when documenting a bug or technical problem.

## Structure

### Problem
What happened?

### Cause
What caused the issue?

### Investigation
How was the cause identified?

### Solution
What was changed?

### Result
What improved?

### Learning
What was learned?
